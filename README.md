# AleksSamArt

Сайт-портфоліо художника (AleksSamArt): вітрина робіт із можливістю **замовити картину** або **купити вже готову**. Багатомовний, без бази даних, працює на безкоштовному хостингу Netlify.

## Можливості

- **Повноекранний вертикальний скрол** — 1 екран = 1 робота; зображення виглядають як картки, що лежать на стосі (анімації GSAP + ScrollTrigger).
- **Лайтбокс** — клік на зображення відкриває перегляд із додатковими фото роботи (етапи, ракурси).
- **«Замовити»** — індивідуальна робота: вибір формату A4/A3 і кількості людей, ціна підставляється автоматично.
- **«Купити»** — готова робота з фіксованою ціною за твір.
- **Форми через Netlify Forms** — замовлення збираються без сервера; email-сповіщення налаштовуються в Netlify Dashboard (див. «Отримання замовлень»).
- **10 мов** — українська (основна, на корені `/`) + en, de, fr, es, it, no, pl, sv, cs. Автовибір мови за мовою браузера.
- **Проданий твір / замовлення** — префікс `SOLD-` або `ORDER-` у назві папки роботи керує її поведінкою в стосі.

## Технічний стек

| Шар | Технологія |
|---|---|
| Генератор | **Astro** (SSG) — статичний вивід, гарне SEO |
| Анімації | **GSAP + ScrollTrigger** |
| Зображення | **astro:assets** — оптимізація на build (WebP, до 2048px) |
| Форми | **Netlify Forms** |
| Хостинг | **Netlify (free)** — деплой з git |

## Структура проєкту

```
src/
├── components/      # секції, картки робіт, лайтбокс, форма
├── layouts/         # базовий layout, футер
├── pages/           # сторінки (мультимовні маршрути)
├── i18n/            # словники перекладів (10 мов)
├── config/          # розміри/ціни, порядок робіт, соцмережі
├── lib/             # клієнтські хелпери
├── styles/          # глобальні стилі, токени
└── assets/works/    # папки робіт: папка = робота, зображення
public/              # статика
netlify.toml         # деплой, env, redirects
```

### Як додати роботу

1. Покласти папку в `src/assets/works/<Назва роботи>/`.
2. Головне фото — файл із числом `1` у кінці назви (`<name>-1.jpg`); решта файлів — додаткові (етапи, ракурси).
3. Дописати назву папки в кінець списку `WORKS_ORDER` у `src/config/works-order.ts` — робота з'явиться знизу стосу.
4. Задеплоїти (новий коміт).

Префікси назв папок:
- `SOLD-` — проданий твір: виключається зі стосу.
- `ORDER-` — робота клієнта: лишається в стосі, на картці бейдж «Замовлення», префікс прибирається з назви.

Кнопка «Купити» — на кожній роботі, крім замовлень. Ціни готових портретів завжди в EUR: Robbie Williams — 100 €, Drew Barrymore і Dua Lipa — 70 €, решта — 50 €.

Індивідуальні портрети: для України (мова браузера `uk`/`uk-UA`) ціни в UAH — A4: 2000/3000, A3: 3500/5000 (1/2 людини); для інших мов — EUR — A4: 80/120, A3: 130/180.

## Env-змінні

Копія: `cp .env.example .env`. Всі змінні публічні й дублюються в `netlify.toml` / Netlify Dashboard.

| Змінна | Призначення |
|---|---|
| `CONTACT_EMAIL` | ⚠️ Не керує доставкою замовлень — зарезервований на майбутнє (напр., mailto). Пошту отримувача задають у Dashboard → Forms → Notifications |
| `FACEBOOK_URL` | Посилання на Facebook |
| `INSTAGRAM_URL` | Посилання на Instagram |

## Отримання замовлень (email)

Замовлення з форм Netlify зберігає і обробляє **сам Netlify** — без сервера. Щоб вони реально приходили на пошту:

1. **Де лежать замовлення:** Netlify Dashboard → **Forms** → форма **«order»** → **Submissions**. Сюди потрапляє кожне надіслане замовлення, незалежно від налаштувань сповіщень.
2. **Email-сповіщення** (без нього листи не йдуть): Dashboard → **Forms** → «order» → **Form notifications** → **Add notification** → **Email notification** → вписати email отримувача.
3. Сповіщення діють **тільки на нові** замовлення — вже надіслані лишаються лише в Submissions.
4. Free-план має ліміт (~100 перевірених сабмітів/міс) — кожен тест його витрачає. Зберігання сабмітів не вічне: для персональних даних (ім'я, email, фото) радимо регулярно експортувати в CSV і видаляти.

> ⚠️ `CONTACT_EMAIL` в env-змінних **не керує доставкою** замовлень — це мертвий конфіг. Пошта отримувача задається лише кроком 2, у Dashboard.

## Команди

```bash
npm install       # встановити залежності
npm run dev       # локальний dev-сервер
npm run build     # збірка статики
npm run preview   # перегляд збірки локально
```

## Розгортання

- Деплой на Netlify: `netlify deploy` або push у підключений репозиторій.
- Build command: `npm run build`, publish directory: `dist` (задано в `netlify.toml`).
- Env-змінні — у Netlify Dashboard (або через `netlify.toml`).
- `uk` живе на корені `/`; заходи на `/uk/...` перенаправляються на корінь (301, у `netlify.toml`).
