# План дій — AleksSamArt

Сайт-портфоліо художника з можливістю **замовити** або **купити** роботу. Без БД, на Netlify (free), зображення з публічного Google Drive.

Джерела вимог: [`CLAUDE.md`](CLAUDE.md) (архітектура, дизайн, стек) та [`idea.txt`](idea.txt) (початковий задум).

> Цей файл — **живий документ**: статуси оновлюються в міру виконання. Після кожного етапу створюється хендоф для наступної сесії (див. [Процес](#процес)).

---

## Процес

- Кожен етап — окремий блок робіт із **ціллю** та **критеріями приймання**.
- Поки етап не завершено, його «Що було виконано» заповнюється по ходу.
- **Після завершення етапу**:
  1. Перевірити всі критерії приймання.
  2. Оновити статус етапу в цьому файлі на `✅ виконано` (і `❌ / ⚠️` якщо частково).
  3. Створити `handoffs/HANDOFF-<NN>.md` за [шаблоном](#шаблон-хендофа) — щоб наступна сесія розуміла стан без перечитування всього коду.
  4. Оновити розділ «Наступні дії» для поточного етапу (або перенести відкладені пункти в наступний).
- Локаль теж оновлюється: в `src/config` дефолти розмірів/цін з CLAUDE.md (A2=300, A3=200, A4=100) — тимчасові.

## Конвенція хендофів

- Файли: `handoffs/HANDOFF-<NN>.md`, де `NN` — номер етапу (наприклад `HANDOFF-02.md` — після етапу 2).
- `HANDOFF-00.md` — початкова точка проєкту та результат етапу 0.
- Останній актуальний хендоф — це те, з чого починає наступна сесія.

### Що було виконано

Бічна навігація-точки (`data-dots`/`data-dot`, aria-мітки з назв робіт). Підключено клієнтський скрипт `src/lib/gallery.ts`.
- **`src/lib/gallery.ts`** — клієнтська логіка (через `<script>` у Home):
  - **Ефект «стосу»**: ScrollTrigger `scrub`, діапазон `top bottom → bottom top` (200vh). Картка в'їжджає зі стосу (rotation 3.5° → 0°, scale 0.92 → 1, тінь глибшає), на виході «осідає» назад (rotation −3°, scale 0.96). «Стіс» позаду (2 підкладені картки) — легкий паралакс. Паралакс інтро-екрана.
  - **Активна точка**: рахунок від геометрії екранів (середина в'юпорта) на `scroll`/`resize` через `requestAnimationFrame` — стійко до resize, без залежності від IntersectionObserver. Клік по точці → `scrollIntoView({ behavior: 'smooth' })`.
  - **Стійкість**: `ScrollTrigger.config({ ignoreMobileResize: true })` + `refresh()` на `load`.
  - **`prefers-reduced-motion`**: GSAP-анімації вимикаються, навігація точками лишається.
- **`src/layouts/BaseLayout.astro`** — персистентний футер поверх екранів: іконки Facebook/Instagram (inline SVG) із `SOCIAL_LINKS` (`src/config`, env `FACEBOOK_URL`/`INSTAGRAM_URL`) + копірайт. Іконки з'являються, коли URL задано в env; без env футер — лише копірайт.
